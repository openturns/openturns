Ames Housing dataset
====================

This dataset is a simplified version of the one provided by the R package AmesHousing_ (only 10 predictors have been kept).
It contains the sale price of houses in the city of Ames along with a number of features (construction year, surface area of
floors, garage capacity...).

.. _AmesHousing: https://cran.r-project.org/web/packages/AmesHousing/index.html
